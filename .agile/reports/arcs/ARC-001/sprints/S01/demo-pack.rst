Demo Pack: Sprint S01
=====================

Demo Steps
----------

1. Start server

::

   cd <workspace>
   lamecoder ui

2. Create sessions

- Click **New** twice.
- Rename one session (✏️) and pin it (📍).

3. Continue a conversation

- Select a session.
- Type multi-line code in the composer.
- Press **Ctrl+Enter**.
- Observe streaming reply and that messages persist.

4. Restart verification

- Stop server.
- Start again from the same directory.
- Observe sessions and messages still present.

Expected Visuals
----------------

- Sidebar shows sessions with title, timestamp, snippet.
- Conversation has role badges and timestamps.
- Code blocks show a **Copy** button.
- Composer editor has line numbers and supports Ctrl+F.
