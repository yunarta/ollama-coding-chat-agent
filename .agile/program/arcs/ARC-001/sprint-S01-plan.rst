Sprint S01 Plan
===============

Sprint Goal
-----------

Deliver end-to-end usable UI:

- Session picker + conversation viewer + continue conversation
- CodeMirror-based composer/editor

Scope
-----

Committed
~~~~~~~~~

- Backend session store (``.lame/sessions``) with API endpoints
- Frontend sidebar session list, conversation rendering, and composer
- Streaming response via NDJSON (lightweight)
- Minimal polish: pinned sessions, rename, copy code buttons

Deferred
~~~~~~~~

- Diff viewer / patch approval
- Full observability dashboard
- Multi-agent orchestration
